中国载人登月任务互动课堂｜课堂交互版 V4

使用方法
1. 完整保留本文件夹。
2. 双击 index.html。
3. 从首页进入任意关卡。
4. 全部内容均可离线运行。

课堂交互
- 右侧任务路线标出当前关卡和任务时标。
- 本关步骤可以直接查看；支持“上一步”和“重试本步”。
- “提示”按钮显示本步关键规律；顶部可暂停动画讲解。
- 燃料或电量不足时会出现醒目的颜色、闪烁和声音预警。

版本口径
- 任务流程依据中国载人航天工程办公室公开信息。
- 轨道关系采用标准二体轨道与任务阶段的教学模型。
- 天体大小、航天器大小、距离和时间均经过压缩，不用于真实飞行控制。
- 航天器外形为自制工程科普示意，不代表最终定型产品。
