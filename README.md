# 中国载人登月任务互动课堂 V4（Lunar Mission Classroom）

中国科技馆航天科普互动课件：中国载人月球探测任务**全流程**交互式课堂。
从双箭发射到月地返回共 **8 个关卡**，纯网页实现，全部内容可离线运行。

## 这是什么

面向中小学课堂与展厅讲解的互动教学软件。学生跟随任务路线逐关操作，每一步都有提示与关键规律讲解；燃料或电量不足时会出现颜色、闪烁和声音预警。

任务流程依据中国载人航天工程办公室公开信息；轨道关系采用标准二体轨道与任务阶段教学模型。详细的科学口径与公开依据见 [science-notes.md](science-notes.md)。

## 八个关卡

1. **双箭发射** — 竖直上升、俯仰转弯、分级加速
2. **地月转移** — 瞄准月球未来位置的椭圆转移（霍曼转移教学模型）
3. **近月制动** — 逆速度方向点火：双曲线掠过 → 捕获椭圆 → 环月圆轨
4. **月轨交会** — 低轨调相 + 切向点火 + 转移椭圆交会
5. **月面着陆** — 离轨、动力下降、低速近垂直着陆（月球没有大气，用不了降落伞）
6. **月面活动** — 出舱、月球车低重力行驶、采样、仪器部署
7. **月面起飞** — 上升级分离、入环月轨道、交会与人员样品转移
8. **月地返回** — 转移窗口点火、再入走廊修正、开伞着陆

## 快速开始

**方式一：网页版（推荐用于学习和二次开发）**

双击 `index.html` 即可（推荐 Chrome / Edge），无需安装、无需联网。

**方式二：Windows 便携版（推荐用于展厅大屏）**

从 [Releases](../../releases) 下载 exe，双击即进入全屏课堂模式，无需安装浏览器。
（首次运行如提示"未知发布者"，点"更多信息"→"仍要运行"。）

## 课堂交互设计

- 右侧任务路线标出当前关卡和任务时标
- 每关步骤可查看，支持「上一步」「重试本步」
- 「提示」按钮显示本步关键规律；顶部可暂停动画讲解
- 资源（燃料/电量）不足时有醒目的颜色、闪烁和声音预警

## 科学准确性

- 轨道动画保持轨道形状、焦点位置、切向点火方向、速度变化和相对运动关系正确，尺度与时间经过压缩（页面顶部持续提示）
- 未公开的精确轨道参数、发动机程序、最终外形不作确定性展示
- 公开依据：中国载人航天工程办公室、国家航天局嫦娥五/六号任务公开资料、NASA/JPL 教学文档（详见 [science-notes.md](science-notes.md)）
- 物理自检：`node tests/physics-audit.js`
- ⚠️ 本软件用于科普教学，不用于真实飞行控制
